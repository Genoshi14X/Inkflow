# Inkflow для macOS

Inkflow помогает подготовить перевод манги: увеличить сканы, распознать и проверить реплики, удалить исходные надписи и разместить новый текст поверх страницы.

**Папка сканов → апскейл ×2 → OCR → перевод → ретушь → текстовые слои → готовый PNG.** Отдельно можно экспортировать текст главы в TXT. Этапы выбираете вы: апскейл, перевод и редактирование изображений необязательны.

| Возможность | Что доступно |
|---|---|
| Апскейл | Все изображения главы ×2 через nunif / waifu2x, автоматическая замена рабочих изображений в приложении |
| Распознавание | Локальный Apple Vision OCR, рамки реплик, предварительный порядок чтения |
| Проверка реплик | Редактирование, перестановка, объединение, исключение, удаление и добавление облачков |
| Перевод | Обмен текстом с Яндекс Переводчиком через браузер, сохранение русского черновика |
| Ретушь | Кисть с сохранением текстуры или сглаживанием, настройка размера и отмена мазков |
| Текстовые слои | Системные шрифты, жирный и курсив, подчёркивание, зачёркивание, прописные, цвет и интервалы |
| Размещение текста | Перемещение мышью, восемь маркеров рамки, перенос строк, порядок и видимость слоёв |
| Экспорт | TXT главы и PNG выбранной страницы с текстом в полном разрешении |
| Сохранение | Автоматическое сохранение проекта рядом со сканами, восстановление рабочих изображений и слоёв |

## Запуск и требования

После [сборки из исходников](#разработка) откройте **`dist/Inkflow.app`** двойным щелчком. Приложение предназначено для Apple Silicon и macOS 13+. Проверено на M1 Pro с macOS 26.5.2; более старые версии macOS отдельно не проверялись.

| Инструмент | Что нужно |
|---|---|
| OCR, проверка реплик, текстовые слои и экспорт | Собранный Inkflow; Python и API-ключи не требуются |
| Апскейл | Отдельная установка [nunif](https://github.com/nagadomi/nunif) с Python, зависимостями и моделями waifu2x |
| Кисть восстановления | Python окружения nunif с `opencv-python-headless` и Pillow |
| Перевод в Яндексе | Браузер и интернет |

OCR, апскейл, ретушь и размещение текста выполняются локально. Для первоначальной установки зависимостей и моделей нужен интернет. При переводе вставленный текст обрабатывается Яндексом; изображения Inkflow туда не отправляет.

## Быстрый сценарий

1. **Откройте папку главы.** Поддерживаются PNG, JPG и JPEG непосредственно в папке. Страницы сортируются по числам в имени: `1, 2, …, 10`.
2. **При необходимости увеличьте сканы.** Нажмите **Апскейл папки ×2**. Готовые варианты автоматически станут рабочими изображениями в Inkflow.
3. **Распознайте и проверьте реплики.** Нажмите **Распознать главу**, исправьте текст и порядок. Сохраните английский TXT, если он нужен отдельно.
4. **Подготовьте перевод.** Используйте **Яндекс Переводчик…** или впишите перевод отдельных реплик вручную в режиме **Перевод / EN + RU**.
5. **Удалите исходные надписи.** Включите **Кисть восстановления** и закрасьте текст на странице после подготовки перевода.
6. **Разместите новый текст.** Нажмите **Добавить текст**, выберите шрифт и начертание. Перемещайте слой мышью, меняйте рамку за маркеры.
7. **Сохраните готовую страницу.** Во вкладке **Текст на странице** нажмите **Экспорт страницы в PNG…**. Файл появится в выбранной папке; по умолчанию — `exports/` внутри главы.

## Распознавание и проверка реплик

**Распознать главу** обрабатывает страницы по очереди. **Распознать страницу** работает с выбранной страницей. Остановка завершает текущую страницу, а продолжение обрабатывает оставшиеся. Уже распознанные страницы повторно не обрабатываются, чтобы сохранить ручные правки.

- Нажатие на рамку поверх изображения выбирает реплику и прокручивает к ней список справа.
- Текст справа можно редактировать; стрелки меняют порядок реплик.
- Снимите **В TXT**, чтобы исключить звук или лишнюю надпись из экспорта.
- В меню `…` доступны объединение со следующей репликой, исходный OCR и удаление блока.
- Если текст пропущен, нажмите **Добавить облачко** и обведите его мышью. Реплика добавится в конец списка; переставьте её стрелками. При неудачном распознавании введите текст вручную.
- Чтобы разделить ошибочно объединённый блок, исключите его и добавьте облачка по отдельности.

После проверки нажмите **Отметить как проверенную**, затем **Экспорт TXT…**. По умолчанию файл называется как папка главы, например `155.txt`. Непроверенные и нераспознанные страницы помечаются в TXT.

## Апскейл ×2 через nunif

Нажмите **Апскейл папки ×2** над изображением. Все страницы открытой главы обрабатываются по очереди с прогрессом. После каждой страницы улучшенный PNG становится её рабочим изображением: просмотр, OCR и дальнейшие правки используют новый вариант.

Порядок страниц, реплики, переводы и текстовые слои сохраняются. Положение и типографика слоёв масштабируются пропорционально изображению. Отметки проверки снимаются; история отмены очищается при замене рабочих изображений.

Результаты сохраняются в `upscaled/<идентификатор запуска>/<имя исходника>_x2.png` внутри папки главы. Оригиналы остаются на диске. При остановке или ошибке готовые страницы остаются улучшенными, остальные — в прежнем виде. **Повторное нажатие увеличивает все текущие рабочие изображения ещё вдвое.**

Inkflow автоматически ищет `~/Downloads/nunif` и Python в `.venv/bin/python` или `venv/bin/python`. Если установка не найдена, приложение предложит выбрать папку nunif и Python его окружения. Выбор сохраняется; запуск из Finder поддерживается.

Для каждой страницы передаются фиксированные параметры:

```sh
python -m waifu2x.cli -i input -o output --method scale2x --noise-level 1 --format png
```

Работа идёт в фоне; **Остановить** прерывает процесс. Inkflow проверяет успешное завершение и удвоение размеров изображения. Модели и зависимости автоматически не устанавливаются.

## Удаление текста кистью

После подготовки перевода включите **Кисть восстановления** над страницей. Настройте размер в пикселях рабочего изображения, увеличьте масштаб при необходимости и закрасьте надпись целиком с небольшим запасом фона. Восстановление выполняется после отпускания мыши. Одиночный щелчок оставляет круглый мазок; рамки OCR во время ретуши скрыты.

| Режим | Как работает |
|---|---|
| **Сохранять текстуру** — по умолчанию | Подбирает соседние фрагменты по границе мазка и переносит их, сохраняя зерно и растр без усреднения |
| **Сглаживать** | Восстанавливает фон через OpenCV Telea; подходит для ровных облачков, но может размывать растр |

Каждый мазок сохраняется отдельным PNG в `edited/` и сразу становится рабочим изображением. Реплики, переводы и текстовые слои остаются в проекте. Кисть изменяет растровое изображение под слоями; чтобы убрать добавленный текстовый слой, скройте или удалите сам слой.

Стрелка рядом с размером кисти или `⇧⌘Z` отменяет последнюю правку, включая мазок. Текущий результат восстанавливается после открытия главы. Кнопка с папкой показывает рабочий PNG в Finder.

Для кисти установите OpenCV в Python окружения nunif, например:

```sh
~/Downloads/nunif/venv/bin/python -m pip install opencv-python-headless
```

Лучше работать небольшими мазками. В режиме текстуры возможны повторения узора и неточное продолжение линий. Скрытые буквами детали нельзя восстановить точно по одному изображению. Режим применяется к новым мазкам; сохранённые ранее мазки автоматически не пересчитываются. Исходник и предыдущие PNG сохраняются, OCR после стирания автоматически не запускается.

## Текст поверх страницы

Нажмите **Добавить текст** над изображением. Справа откроется вкладка **Текст на странице**. Введите или вставьте перевод, выберите установленный шрифт через поиск и настройте слой. Если перед добавлением выбран блок OCR с переводом, новый слой получит его рамку и перевод.

### Шрифт и форматирование

| Параметр | Действие |
|---|---|
| Шрифт | Поиск среди установленных системных шрифтов и начертаний |
| **B** | Жирный |
| **I** | Курсив |
| **U** | Подчёркивание |
| **S** | Зачёркивание |
| **TT** | Все прописные; исходный регистр в поле ввода сохраняется |
| Размер, px | Размер шрифта в пикселях рабочего изображения |
| Ширина / высота букв, % | Горизонтальное и вертикальное масштабирование букв, от 50 до 200% |
| Межстрочный / межбуквенный, px | Дополнительные интервалы между строками и буквами |
| Выравнивание | Слева, по центру или справа; отдельно — центрирование по высоте блока |
| Цвет | Выбор цвета текста |

Переключатели можно сочетать. **Форматирование применяется ко всему слою.** Разные стили отдельных слов или букв внутри одного слоя пока не поддерживаются.

Для B/I выбирается настоящее начертание шрифта. Если его нет, используется искусственная жирность или наклон с пометкой в панели. Для другой насыщенности, например Light, Medium или Black, выберите соответствующее установленное начертание в списке шрифтов. Выбор начертания обновляет состояния B/I. Если шрифт проекта больше не установлен, Inkflow использует системный и показывает предупреждение.

### Рамка и слои

- Перетащите блок мышью, чтобы переместить текст по странице.
- Тяните угловой маркер рамки для изменения ширины и высоты, боковой — для изменения одной стороны. У рамки восемь маркеров.
- Текст переносится по новой ширине, размер шрифта сохраняется. Если текст не помещается по высоте, появляется подсказка.
- Координаты и размеры блока можно задать численно. Изменение поля подтверждается Enter или переходом к другому полю.
- Выбирайте слои в списке, скрывайте их, меняйте порядок кнопками **Выше / Ниже** или удаляйте. Новые слои появляются поверх предыдущих.

Перемещение и изменение рамки отображаются сразу, сохраняются после отпускания мыши и отменяются одной правкой. Слои остаются редактируемыми после открытия проекта и сохраняются при апскейле, ретуши и OCR. Поддерживается горизонтальный текст без поворота и обводки.

### Экспорт PNG

**Экспорт страницы в PNG…** во вкладке **Текст на странице** сохраняет выбранную страницу с видимыми слоями в полном разрешении, без рамок редактора. Папка по умолчанию — `exports/` внутри главы.

Экспорт не меняет рабочее изображение и редактируемые слои. Исходные и рабочие файлы защищены от перезаписи. TXT-экспорт по-прежнему содержит реплики OCR и их переводы, независимо от размещённого поверх страницы текста.

## Перевод на русский через браузер

1. Распознайте главу и проверьте английские реплики и их порядок.
2. Нажмите **Яндекс Переводчик…**, затем **Скопировать EN и открыть Яндекс**. В браузере откроется [перевод с английского на русский](https://translate.yandex.ru/?source_lang=en&target_lang=ru). Вставьте оригинал в левое поле: `⌘V`.
3. Скопируйте русский результат в браузере, вернитесь в Inkflow и нажмите **Добавить перевод из буфера**. Текст добавится в конец черновика; его можно исправить прямо в поле.
4. Нажмите **Сохранить RU TXT…**. Имя по умолчанию — `155_ru.txt`; английский экспорт `155.txt` остаётся отдельным файлом.

В браузер копируется оригинальный TXT главы с заголовками и порядком реплик. Длинный текст разбивается на части до 9500 единиц UTF-16 с предпочтением границ строк. Переводите части по очереди: очищайте предыдущее содержимое слева в Яндексе и добавляйте каждый перевод один раз. Вставка и копирование выполняются вручную.

Черновик автоматически сохраняется в проекте, но не разбивается обратно на облачка и не обновляется при изменении оригинала. Для размещения текста скопируйте нужную реплику из черновика в текстовый слой. Переводы отдельных реплик и режимы TXT **Перевод / EN + RU** доступны для ручной работы и независимы от черновика Яндекса.

## Сохранение проекта и файлов

**Правки сохраняются автоматически** в скрытом файле `.mangascan.json` внутри папки главы. Имя сохранено для совместимости с первой версией приложения. При повторном открытии исходной папки восстанавливаются реплики, их порядок и переводы, исключённые блоки, отметки проверки, рабочие изображения, текстовые слои и русский черновик.

| Файл или папка | Содержимое |
|---|---|
| Исходные PNG/JPG/JPEG | Оригиналы страниц в корне папки главы |
| `.mangascan.json` | Текст, настройки, слои и ссылки на рабочие изображения |
| `upscaled/` | Результаты апскейла |
| `edited/` | PNG после мазков кисти, включая предыдущие версии |
| `exports/` | Готовые PNG с текстом, если сохранены в папку по умолчанию |

**Переносите и храните всю папку главы целиком.** Одного `.mangascan.json` недостаточно: рабочие изображения находятся в `upscaled/` и `edited/`. Экспортированный PNG — готовая картинка; для дальнейшего редактирования слоёв нужен проект.

Если проект повреждён, Inkflow сообщает об ошибке и не перезаписывает его. Если рабочее изображение изменилось или отсутствует, приложение показывает предупреждение и сохраняет текстовые правки. Папка должна быть доступна для записи.

Формат проекта — версия 2, чтение версии 1 поддерживается. Не сохраняйте проект с новыми слоями и настройками в старой версии Inkflow и не редактируйте одну главу одновременно в нескольких экземплярах приложения.

### Клавиши и отмена

| Клавиши | Действие |
|---|---|
| `⌘O` | Открыть папку |
| `⌘S` | Сохранить проект |
| `⌘E` | Экспорт TXT |
| `⇧⌘Z` | Отменить последнюю правку Inkflow, включая мазок или изменение слоя |

История отмены хранится до закрытия приложения или смены главы. При апскейле она очищается после замены рабочих изображений. Текущий сохранённый результат остаётся в проекте.

## Ограничения распознавания

OCR настроен на английский язык. Панели выделяются по светлым промежуткам: сначала горизонтальные разделители, затем вертикальные с обходом справа налево. Строки объединяются по близости и выравниванию внутри панели. Это геометрическая эвристика, которая требует проверки редактором.

- Нестандартные, вложенные и диагональные панели, развороты и облачка поверх нескольких панелей могут определяться неверно.
- Смысл диалога не анализируется; порядок реплик не всегда восстанавливается одной геометрией.
- Звуки и фоновые надписи нужно исключать из TXT вручную.
- Возможны ошибки букв, пунктуации и имён даже при высокой уверенности OCR. Замены похожих кириллических символов отмечаются предупреждением; исходный текст доступен в меню блока.
- Вложенные папки не обходятся. Изменённые исходники автоматически повторно не распознаются.

## Проверки

Основной набор тестов проверяет распознавание на синтетических изображениях, порядок и редактирование реплик, сохранение, отмену, совместимость проектов, разбивку текста для браузера, пакетный апскейл и текстовые слои.

Для новых инструментов проверены обработка ошибок и остановка, восстановление рабочих изображений после открытия, сохранность переводов и слоёв, перетаскивание и изменение рамки одним жестом, начертания, кириллица, скрытые слои и PNG-экспорт. Проверки кисти через реальный Python запускаются отдельно. Через интерфейс проверены мазки и их отмена, выбор шрифтов, форматирование, маркеры рамки, перемещение текста и экспорт PNG.

## Разработка

Swift-приложение использует SwiftUI, AppKit, Vision и ImageIO без сторонних Swift-пакетов. Апскейл и ретушь запускают отдельные Python-процессы.

| Исходник | Назначение |
|---|---|
| `App/Core.swift` | Данные проекта, OCR, порядок чтения, TXT, сохранение |
| `App/Model.swift` | Состояние приложения, действия и фоновые задачи |
| `App/Inkflow.swift` | Основной интерфейс и кисть на странице |
| `App/Upscale.swift` | Запуск nunif и проверка результатов |
| `App/Healing.swift` | Запуск восстановления фона |
| `App/TextLayers.swift` | Типографика, работа с рамками, панель текста, PNG-экспорт |
| `scripts/heal-image.py` | Восстановление текстурой и OpenCV Telea |

Для сборки нужны инструменты разработчика Apple со Swift:

```sh
./scripts/build.sh
./scripts/test.sh
```

Дополнительные проверки с локальными зависимостями:

```sh
# Кисть: Python с OpenCV, NumPy и Pillow
INKFLOW_HEALING_PYTHON=~/Downloads/nunif/venv/bin/python ./scripts/test.sh

# Реальный запуск nunif на синтетических изображениях
INKFLOW_NUNIF=~/Downloads/nunif ./scripts/test.sh

# OCR пяти частных образцов и сравнение с ручной разметкой
INKFLOW_PRIVATE_SAMPLES=1 ./scripts/test.sh
```

Последний набор требует локальных `samples/`, файлов разметки в `output/` и Python 3. Основные тесты используют синтетические изображения и не требуют страниц манги. Проверки интеграции кисти пропускаются, если `INKFLOW_HEALING_PYTHON` не задан.

Сборка создаёт `dist/Inkflow.app` и подписывает его локальной ad-hoc подписью. Это не нотарифицированный дистрибутив для распространения. Иконка собирается автоматически; [исходник и промпт](docs/icon.md).

Документация зависимостей: [Apple Vision](https://developer.apple.com/documentation/vision/recognizing-text-in-images), [SwiftUI](https://developer.apple.com/documentation/swiftui), [nunif / waifu2x](https://github.com/nagadomi/nunif).

## Репозиторий и локальные материалы

Публичный репозиторий: [Genoshi14X/Inkflow](https://github.com/Genoshi14X/Inkflow). В Git входят исходники, иконка и скрипты. Папки `samples/`, `output/`, `dist/`, `bin/`, сохранённые проекты и локальные настройки исключены из Git.

`Sources/ocr.swift` и локальный `scripts/report.py` сохранены от первого эксперимента. `output/review.html`, `output/verified.txt` и `output/reference.json` содержат ручную проверку этого эксперимента. `samples/01.png`–`05.png` — копии вложений в порядке отправки, а не номера страниц главы. Эти локальные материалы не входят в публичный репозиторий.
